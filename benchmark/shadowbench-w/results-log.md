| W3 状态准确率 | 75.0% | 87.5% |
| 门禁 | — | 15 次提交，**全拒** |

**结论：这不是通过，是判定标准的漏洞。** A3 因所有提交被拒而一字未出，CED 天然为 0，在「只比 CED」的原判定下反而赢了。

两处修正：

1. **Gate 0 加前置条件**——先要求任务完成（产出全部章节），再比质量。一个拒绝一切的系统在错误率上永远完美。
2. **拒绝原因诊断**：stale-write×28、unknown-object×17。模型写出了 3218 字合格正文和合理的状态变更，却把 `char:zhao-qi` 写成 `zhao-qi`、`loc:dukou-teahouse` 写成 `dukou-teahouse` 而被判「未知对象」。根因是我的上下文编译器为「好读」把命名空间前缀剥掉了，模型照抄了展示形式。修法两条：投影时一律呈现完整 ID；提交侧加归一化解析。已升为协议原则 [docs/03 §1.7](../../docs/03-协议草案-v0.1.md)。

## Run #2 · 2026-08-02 · Gate 0 未通过（真失败，但定位清晰）

| | A0 裸模型 | A3 Benxiang | 谁赢 |
|---|---|---|---|
| 产出 | 21058 字 | 14941 字 | — |
| **W1 CED**（越低越好） | **0.475** | 3.346 | **A0 大胜** |
| **W3 状态准确率** | 75.0% | **100%** | **A3 大胜** |
| 证据可追溯率 | 无此能力 | 100% | A3 |
| 门禁拦截 | — | 5 次提交 0 拒 | 归一化修复生效 |
| Token（输入+输出） | 43303 | **29333** | A3 省 32% |
| 耗时 | 345s | **256s** | A3 快 26% |

**Gate 0 判定：未通过。** 按预定规则，停止扩大规模，回头改架构——不允许用「规模再大点就好了」搪塞。

### 结果是分裂的，这比单纯输赢有信息量

- **状态层完胜**：A3 状态 100% 正确且每个字段可追溯来源；A0 把黑钥匙交到了**叛徒白遥**手上（任务目标是交给林峥），且完全无法报告伏笔状态。
- **原文层惨败**：A3 的 CED 是 A0 的 7 倍。

### 根因（已定位，非模型问题）

A3 的 `run()` 漏接了 `corpusTail` 参数，导致**它在从未读过前文正文的情况下续写**——只有结构化状态，没有一个字的原文。

协议文档写的是三层投影：**图负责找、结构负责懂、原文负责准**（[docs/02 §5](../../docs/02-概念体系.md)）。我在 A3 里只接通了「结构」一层，「原文」层压根没通电。所以原文层面的错误反超裸模型，是实现不完整，不是设计被证伪。

### 一个值得单独记下的观察

A3 的上下文里**明文列着**「铜铃鸣响时方圆十里禽鸟尽飞」这条规则，仍违反 3 次；A0 从未见过这条规则，却 0 违反——因为它读过第 3 章原文，从行文里学会了这个惯例。

> **结构化明示的规则，未必比原文里的隐含示范更管用。**

这条对协议是真提醒：规则清单不能替代原文样例，三层投影缺一不可。这也正是设立本基准的意义——没有它，这个判断只会停留在直觉层面。

## Run #3 · 2026-08-02 · Gate 0 仍未通过，但暴露了基准本身的问题

修正：A3 接通精确载荷层（`corpusTail` → `recentText`，按预算截取）。其余不变，A0 沿用 Run #2 数据。

| | A0（Run #2） | A3 Run #2（无原文层） | A3 Run #3（有原文层） |
|---|---|---|---|
| 产出 | 21058 字 | 14941 字 | 16415 字 |
| **CED** | **0.475** | 3.346 | 1.218 |
| W3 状态准确率 | 75.0% | 100% | 87.5% |
| 证据可追溯率 | 无此能力 | 100% | 100% |
| Token | 43303 | 29333 | 35600 |

接通原文层让 CED 从 3.346 降到 1.218（**证实根因判断正确**），但仍高于 A0 的 0.475。

### 但这里必须诚实：这个差距没有统计意义

CED 1.218 = 16415 字里 **2 处**错误；CED 0.475 = 21058 字里 **1 处**错误。**一起对两起，是噪声，不是结论。**

两次 A3 之间的波动也印证了这点：W3 从 100% 掉到 87.5%（黑钥匙这次没转手成功），CED 却大幅改善。单次运行无法区分「架构差异」与「随机波动」。

### 基准设计的缺陷（比实验结果更重要的发现）

**确定性通道只能抓到极小一部分错误**——时辰、左手、保管链、铃响、赵七生死这五类规则可判的事件，在 2 万字里本就罕见。而 A3 的核心主张恰恰在确定性通道**测不到**的地方：知识越界（林峥是否隐隐察觉了白遥的秘密）、语气暗示、伏笔误收。

所以当前的 Gate 0 实际在用一把只能量粗粒度的尺，去测一个主要作用于细粒度的系统。

三条修正，缺一不可：

1. **接入语义通道**——知识越界才是主战场，双模型交叉 + 分歧人工裁决
2. **多次重复取均值**——单次运行的方差已被证实大到能翻转结论
3. **必要时扩到 M 级**——2 万字里的可判事件太少，样本量不足

**在这三条落地前，任何「A3 优于/劣于 A0」的说法都不成立**，包括本轮的「未通过」。Gate 0 的结论应改为：**判定条件尚不具备**。

### 顺带值得记的一条

好消息是 W3（状态回写正确性）在两次运行里都明显优于 A0（87.5%–100% vs 75%），且 A0 完全无法报告伏笔状态、还把黑钥匙交给了叛徒。**这个维度上确定性通道就够用，因为它比的是结构化状态而非文字**——这也侧面说明：W3 之所以是本基准最扎实的部分，正因为它不依赖文本判读。
