# ShadowBench-W · 开放榜单（Open Leaderboard）

> **测什么**：长篇小说续写中的**状态回写正确性（W3）**——AI 写了几万字之后，藏在世界状态里的字段（人物关系、秘密暴露、伏笔状态）是否还答得对。
> **为什么需要**：全球没有第二个基准考这道题。检索类基准测「段落找得回找不回」，上下文类基准测「塞进不塞得进」，**没人测「状态有没有被正确地持久化和回写」**。没人定义过的考题，定义者拿标准制定权。

## 榜单规则（先读）

1. **同一套语料、同一个探询口径**：禁止对照臂额外拿到上下文（历史教训：对照臂探询不传对话历史、模板印答案，产出了「标准差为 0 的 75% 墙」——漂亮方差是警报，不是战果，旧数字已作废存档）。
2. **n ≥ 6**，报均值 ± 标准差；差异用**置换检验**（p 值）判定，不用点估计讲故事。
3. **原始结果必须提交入库**（results/ 下 JSON），判分器（eval/）一并公开，任何人可复核。
4. **必须写明限制**：模型、语料来源、n、探询方式。自造夹具的数字只保证「改代码不会让它变差」，不保证真语料上的表现。
5. 本象臂的**门禁规则源与判分器同源**（ced.mjs 同时是本象臂的约束规则），确定性通道上的对比天然带循环论证成分——所以 W3 才只比结构化状态字段，不比文本。

## ⚠ 归因撤回（2026-08-13 · A2 消融 · 论文 v0.4）

**下面 Run #27 的数字没有错，但把它归因给「本象状态层」是错的。**

消融加了一条 **A2 提示词臂**——只告诉模型「每章输出并更新一份显式世界状态」，
**没有校验器、没有证据链、没有上下文编译器**：

| 对比 | 效应 | 显著性（穷举置换，184,756 splits） |
|---|---|---|
| A0 → **A2（只是「要求」）** | **+41.3 pt** | p = 3.3×10⁻⁵ / 2.2×10⁻⁵ |
| A2 → **A3（全套机制）** | **+2.5 pt** | **p = 0.4737 / 0.7214，不显著** |
| Token 成本 | A2 比裸模型**还省** −9.7% / −28.2% | A3 比 A2 贵 +26%~+69% |

两个无关模型（deepseek-v4-flash / qwen-plus）上**小数点级复现**（两边都是 41.3 与 2.5）。

> **在状态准确率上，Origin IR 状态层打不过一句提示词。**
> A3 相对 A0 的 43.8 分优势里，**41.3 分（94%）来自「向基线要了一件从没向它们要过的东西」**。

**唯一幸存的主张（分类性，不是数量性）**：A2 **结构上产不出证据链**——
不是产得差，是提示词里根本没有「信念 vs 依据」的区分。
A3 对 **15.0%（deepseek）/ 27.5%（qwen）** 的受测字段能给出可溯源证据，**A0/A1/A2 均为 0%**。

> **必须回答「你为什么信」的系统才需要这套机器；只回答「你信什么」的不需要。**

原始结果：`results-v3-m/`（A0/A1/A3）+ `results-v3-m-ablation/`（A2），80 份 JSON，判分器指纹已核。
论文：`paper/shadowbench-w-paper-en-v0.4.md` §5.3。
**旧数字保留不删**（墓碑不是删除），但**不得再作为机制优势引用**。

## 当前成绩（2026-08-05 · Run #27，新探询口径）

**W3 状态准确率 · qwen-plus · M 级（9.5 万字）· n=6**

| 臂 | W3 状态准确率 | 置换检验 vs 本象 | 总 Token |
|---|---|---|---|
| **a3 本象**（状态机臂） | **95.8% ± 5.9** | — | 64,612 |
| a0 裸模型（尾部截断） | 52.1% ± 19.7 | p = 0.0024 | 57,598 |
| a1 向量 RAG | 58.3% ± 11.8 | p = 0.0024 | 58,196 |

**臂内跨模型（同口径，n=11）**：qwen-plus 与 deepseek-v4-flash 的 W3 都是 **98.9%**（均值差 0.0000，p = 1.0000），而正文质量差近三倍（W1 EPC 0.20 vs 0.55，p = 0.0392）。

> **状态层的正确性与底模无关，正文层的质量与底模显著相关。**

**字段级分界线**（为什么状态机赢，赢在哪）：

| 字段类型 | 裸模型 | RAG | 本象 |
|---|---|---|---|
| 能从近文直接读出的（钥匙持有者，就写在正文里） | 5/6 | 5/6 | 4/6 |
| 跨几十章累积、从不在任何一段文字里陈述的（秘密暴露） | 1/6 | 0/6 | **6/6** |
| 从不存在于任何一段文字里的（悬疑钩子状态） | 0/6 | 0/6 | **6/6** |

**不主张**（写在这里防止被引用）：
- 不主张「写得更一致」（W1 判分器补词表后优势消失，按接触度归一化三臂持平）
- 不主张「更省 Token」（同口径实测 +12.2%，p = 0.5253，不显著）
- 当前只有 n=6 单模型对照、n=11 臂内；deepseek 侧对照臂尚未用新探询重跑

## 如何上榜

```bash
# 跑自己的臂（或复现现有臂）
node benchmark/shadowbench-w/run.mjs --arm <你的臂> --provider <stub|anthropic|hermes|bailian> --out results/<名字>.json
# 判分
node benchmark/shadowbench-w/eval/state-diff.mjs <结果文件>
```

提交方式：跑通后 PR 进 `results/`，附模型、语料、n、探询口径说明。判分不过关、口径不一致的提交会被拒并说明理由。
