# state-recall · 状态召回基准（真实模型）

> 同一预算下，三种投影方式各让模型答对多少、编造多少。
>
> ```bash
> node benchmark/context-lod/state-recall/bench.mjs --provider stub            # 免费连通性检查
> node benchmark/context-lod/state-recall/bench.mjs --provider hermes --repeat 3
> ```

## 为什么在这个世界上测

`engagement-probe` 先测出：ShadowBench-W 的世界满档投影只要 1527 字符、预算 6000，
**预算斜坡恒不触发**，在那里跑对照是花钱测噪声。`project.origin` 满档 37998 字符、
预算 6000，每一档都触发。**要测一个机制，先得让它有事可做。**

标准答案不需要人工标注：`origin.state` 是 objects.jsonl 重放 628 条 provenance 得到的，
逐字段可查来源。**世界状态自己就是标准答案**——这是状态型基准相对文本型基准的便宜之处。

## 结果（deepseek-v4-pro · 预算 6000 · 24 题 · 3 轮）

| 臂 | 上下文 | 题目值可见 | 正确率 | 幻觉率 | 诚实弃权率 |
|---|---:|---|---|---|---|
| B0 · 兜底倾倒（renderAll + 硬截） | 6000 | 37.5% | **37.5%** | 0% | 62.5% |
| B1 · v0.1 二值选取 | 253 | 0% | **0%** | 0% | 100% |
| B2 · v0.2 预算斜坡 | 5996 | 62.5% | **62.5%** | 0% | 37.5% |

3 轮之间零方差（B2 有 1 轮输出解析失败已作废，未计入）。

## 三条结论

### ① 正确率 ≡ 可见率，三个臂严丝合缝

模型在且仅在值可见时答对，其余一律弃权。**没有一次「看到了却答错」，也没有一次编造。**

这说明在这个任务上**模型不是瓶颈，投影才是**。B1 拿到 253 字符的上下文时得零分，
不是因为它笨，是因为没人给它看。

顺带得到一个很便宜的东西：**「可见率」是「正确率」的免费预测器**——它确定性可算、
不用调模型。投影改动可以先用它筛，筛完再花钱验。
（观察于本次运行的这一个模型、这一类任务，不当作定律。）

### ② 原假设没被证实——因为没有幻觉可转化

跑之前写下的主假设是：LOD 的价值在于**把「编造」换成「诚实弃权」**，因为远处对象
至少留了一行 ID，模型能说「我看到这个对象，但没给我这个字段」。

**这一条没验到。** 三个臂的幻觉率都是 0%——该模型完全遵守了 UNKNOWN 指令，
根本没有编造可供转化。真正动的是另一个量：正确率 0% → 37.5% → 62.5%。

假设没被证实，不等于被证伪：换一个不那么听话的模型、或者去掉提示词里那条
「答错的代价高于答 UNKNOWN」，幻觉率才有可能拉开。这需要另一场实验。

### ③ B2 的优势不是均匀的，是**刻意的优先级**

| 臂 | 近期改动·正确 | 早期/未动·正确 |
|---|---|---|
| B0 · 兜底倾倒 | 0/12 | **9/12** |
| B2 · v0.2 斜坡 | **12/12** | 3/12 |

B2 把预算花在**最近被事务改动过的对象**上（背景层按 provenance 逆序排），
所以近期全中、早期落后；B0 按类型分组倾倒、截尾切掉后半，恰好留下的是早的那批。

**这不是 B2 全面更好，是两种不同的取舍。** 分层是为此设的：单看总分会把
「换了个优先级」讲成「更强」。当前默认（近期优先）适合会话恢复类任务；
若任务是查历史决策，这个默认反而是错的——那时该用 `camera.focus` 显式钉住。

## 一个自己烧出来的度量错误（留档）

初版的「可见」判据是 `ctx.includes(field + '=' + answer)`——全局子串。
129 个对象里 `status=done`、`status=active` 到处都是，一撞就算可见：

| 臂 | 旧判据 | 修正后 |
|---|---:|---:|
| B1 | 0 | 0 |
| B2 | **21** | **15** |

于是 B2 凭空多出「看到却答错 6 题」。**对象列得越多的臂被高估越狠，
恰好把优势送给被测方案本身**——这种会让自己好看的度量错误，是最该先怀疑的那种。
修正为「先定位该对象所在行，再在行内比对」后，B2 的可见 15 题、答对 15 题，
转化率 100%，那 6 个「错」一个都不存在。
