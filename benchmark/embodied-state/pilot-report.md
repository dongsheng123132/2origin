# 首轮多模态三臂试跑报告

> 日期：2026-08-13
> 模型：`qwen3.5-omni-plus`
> 规模：4个摆拍场景、9个检查点、每臂单次运行
> 性质：**装置验证与缺陷发现，不是统计结论**

## 公平口径

- 每道题只提供从0秒到检查点的视频前缀，模型看不到未来；
- 三臂复用完全相同的9个视频前缀、模型、温度和答案格式；
- A0无持久状态；A1携带模型自己生成的显式状态表；A2携带事务状态，但只开结构门禁；
- 另跑探索臂A2G，加入字段域、遮挡可见性和答案—状态一致性门禁，并允许一次纠错；
- 判分器事后读取真值，运行期门禁不读取标准答案。

## 结果

| 臂 | 状态值正确 | 认识论状态正确 | 自信编造 | 说明 |
|---|---:|---:|---:|---|
| A0 无状态 | 7/9（77.8%） | 5/9（55.6%） | 2 | 基线 |
| A1 提示词状态表 | 7/9（77.8%） | 6/9（66.7%） | 2 | 本轮最好，但样本极小 |
| A2 事务结构门禁 | 7/9（77.8%） | 5/9（55.6%） | 2 | 拒绝1次空事务，未阻止语义误判 |
| A2G 探索性语义门禁 | 7/9（77.8%） | 4/9（44.4%） | **0** | 消除编造，但误伤2个本可回答项 |

证据分数暂不作主结论：模型可以密集列出许多秒数，当前“秒点命中率”会被引用数量影响；下一版需改为事件级证据命中，并对无意义的时间点堆砌去重或处罚。

## 三条主要发现

### 1. 当前没有证据表明本象提高状态准确率

A0、A1、A2、A2G状态值都是7/9。A1甚至在认识论标签上暂时领先。这个结果与仓库文本场景的消融方向一致：**要求模型显式维护状态本身就可能得到大部分收益，不能把它归功于事务机制。**

### 2. 结构事务不等于语义安全

A2能拒绝缺少`changes`的空事务，但仍接受了“遮挡期间把最后所见位置称为当前observed”等语义错误。`expected_state_version`、`from`和证据字段存在，不代表证据真的支持结论。

### 3. 简单语义门禁能消除编造，但当前过度保守

A2G把两道遮挡中的错误断言降级为`UNKNOWN`，自信编造从2降到0；但它也把静态持续和重新出现后的正确答案误伤为`UNKNOWN`，没有提高总准确率。

误伤揭示的不是调一个阈值，而是对象模型缺字段：

```text
last_observation:  A.location=M, observed_at=2s
current_belief:    A.location=M, status=inferred, valid_at=7s
source_event:      observation@2s
```

当前单一的`location + epistemic`无法同时表达“这个值曾被直接观察”和“这个值现在只是延续推断”。

## 一个不可绕过的系统边界

隐藏移动题要求系统看到“有人开始接触A、随后进入遮挡”后提高不确定性。仅靠事务编译器无法从像素确定接触事件；它需要上游跟踪器/动作检测器或场景图提交类似：

```json
{
  "event": "contact_started",
  "actor": "human-hand-track-7",
  "object": "A",
  "observed_at": 8.1,
  "evidence": "video#t=8.0,8.3"
}
```

本象可以验证并保存这个事件、据此让旧位置失效，但不能替代产生该事件的感知系统。这进一步支持混合架构，而非“本象包办机器人世界模型”。

## 下一版必须先做的事

1. 新增事件日志与信念投影，分开`observed_at`、`valid_at`、`committed_at`；
2. 状态写入改为`observation event -> deterministic belief reducer -> current projection`，不允许模型直接把事件写成当前事实；
3. 加入`contact_started`、`occlusion_started/ended`、`track_lost/reacquired`、`inside/removed_from`事件类型；
4. 证据按事件判分，加入“引用发生在可见区域/时段”的确定性校验；
5. 用非真值泄漏的策略重跑：规则只看观测事件、时间和旧状态，不看场景标准答案；
6. 扩到真实机器人/多视角/无人工标签物体后，再做重复运行和显著性检验。
