1. **引用先于宣称**——先说清楚对方做了什么、我们从中学到什么，再谈我们在做什么
2. **合作先于对撕**——先行者是盟友，不是竞品；不做「我们比你强」的对比营销
3. **诚实边界**——不宣称尚未实现的能力；本项目当前是 v0.1 文档与协议草案，**没有可运行代码**，这一点必须主动说明
4. **不挖人、不蹭热度**——不邀请对方放弃自己的项目，只谈互操作与标准共建
