## 1. 全球第一个「AI 状态回写正确性」榜单（ShadowBench-W）

**主张**：全球没有「AI 改完世界、世界对不对」的公开考题与榜单。

**证据**（benchmark-landscape.md，2026-08-06 调研）：
- SWE-bench / GAIA / τ-bench / TerminalBench —— 全是 agent 能力榜，不考「状态是否被正确持久化」
- 全球没有持久对象层 / 状态写回验证的 leaderboard → W3 考题空白
- 「没人定义过的考题，定义者拿标准制定权」

**ShadowBench-W 实测数字**（benchmark/shadowbench-w/）：
- 三臂：A0 裸模型 / A1 RAG / A3 本象（上下文编译 + 提交编译）

## 2. 原生电子文档无损结构化的无人区（office 方言）

**主张**：行业火力全在 PDF 扫描件，原生 docx/xlsx/pptx 的无损结构化没人认真做。

**证据**（doc-to-ai-landscape.md，2026-08-05 调研 + 实测）：
- 四层方案全在啃 PDF：pandoc（45.7k★，复杂 docx 漏表）、markitdown（171k★，微软，不还原合并单元格）、MinerU（76.9k★，OCR）、LlamaParse（闭源）
- **OCR 物理误差是天花板**：OmniDocBench（CVPR 2025）表格 TEDS≈0.78，中文更低 0.752
- 原生 docx 信息无损，结构还原可近 100% ——「docx→IR 对象」无人认真做

**本象实测**（adapters/office/）：
- 海事局红头文件 2019 → 409 个结构对象（6 章/77 条/16 表/59 勾选），verify 一致
- 转换即语义事务 + SHA-256 结构指纹可验证（篡改即检出）
- 「别人做把纸猜成字，本象做把字变成可验证状态的对象」

## 3. 「上下文必炸」的解法主张（Shadow Memory / OriginWriter）

**主张**：上下文爆炸不是窗口太小，是聊天记录被当成了世界状态。

**解法**：
- Shadow Memory（MCP Server）：项目状态持久化，新会话秒恢复
- OriginWriter：写作 = 事务（正文 + 状态变更，五道门禁）
- 连「模型记错前值」都被量化成 drift-rate（当前 8.3%，可观测可归零）

**实证**：
- deepseek-v4-flash 续写《月落渡口》ch11：2883 字，自动产出状态变更 + 断言，门禁通过
- 两部连载并行：《月落渡口》（4347 字）+ 《规则怪谈·无限层》（11671 字），状态开源可验证
