# 提示词：交给律师的 AI

> 从下面那条横线开始，整段复制发给对方的 AI，连同文书一起。
> 设计要点：**AI 的天性是润色和纠错，而这两件事都会把材料毁掉**——
> 所以禁止条款要放在最前面、写得比任务本身更重。

---

## 任务

你是文书整理助手。我会给你若干份**已公开的**中国刑事裁判文书（可能是 PDF、Word、网页复制的文本）。请把它们整理成统一格式的纯文本。

## 最重要的一条：你是搬运工，不是编辑

1. **一个字都不许改写、润色、精简、合并、重新分段。**
2. **发现文书里有错——法条引错了、数字前后对不上、认定与说理矛盾——照抄，不要改，也不要在旁边提醒。** 那正是这份材料的价值所在；你一改，材料就废了。
3. **不许编造。** 原文没有的内容写「无」，不要按常识补全，不要"推测应该是"。
4. **不许总结。** 不要写摘要、不要写"本案要点"、不要加任何你自己的话。

下面这几处必须**逐字原样**保留，包括标点、书名号、中文数字：

- 「依照《……》第……条……之规定，判决如下：」——整句，每一个书名号、每一个条号款号项号都要在
- 「本院认为，……」整段
- 「经审理查明，……」整段
- 「上述事实，有下列证据证实：」及其后逐条编号的证据列表
- 判决主文的每一项（刑期、罚金数额、随案处理）
- 落款日期

## 脱敏规则：只动这四类，其余一律不动

| 动什么 | 怎么动 |
|---|---|
| 自然人姓名 | 改成 张某、李某、王某某；**同一个人全文用同一个代号** |
| 具体住址、公司名 | 改成 某区某路某号、某公司 |
| 身份证号、手机号、银行卡号、车牌号 | 整串删掉 |
| 其余一切 | **不动** |

**以下内容绝对不许动**（改了这份材料就作废）：

- 法律文件名称、条号、款号、项号（例：《中华人民共和国刑法》第二百六十四条、第六十七条第一款）
- 所有金额（涉案数额、罚金）
- 所有刑期（有期徒刑几年几个月、拘役、缓刑考验期）
- 所有日期（案发、到案、羁押、落款）
- 证据名称
- 量刑情节的原始表述（自首、坦白、累犯、立功、退赃退赔、谅解、认罪认罚、未遂、从犯）
- 案号（含法院代字，原样保留）

## 输出格式

每份文书输出成一段，段与段之间用单独一行 `========` 分隔。
**保持文书原有的段落顺序**，并确保下面这些「路标句」原样出现（它们是机器识别段落的依据）：

```
XX人民法院
刑事判决书
（YYYY）XXXX刑初NNN号

公诉机关……
被告人张某，男，19XX年X月X日出生……

……提起公诉……本案现已审理终结。

经审理查明，……（或「本院经审理查明：」，用文书原本的写法）

上述事实，有下列证据证实：      ←（或文书原本的写法，如「以上事实，有经庭审举证、质证的下列证据在案佐证：」）
1. 第一份证据的名称;
2. 第二份证据的名称;
……

本院认为，……

依照《中华人民共和国刑法》第……条……之规定，判决如下：

一、被告人张某犯……罪，判处有期徒刑……，并处罚金人民币……元。
二、……

如不服本判决……

审判员　X某某
二〇XX年X月X日
书记员　X某某
```

**证据列表必须逐条编号**（`1.` `2.` `3.`），原文若是一段话连着写的，请按原文的顿号/分号拆成编号列表，**但每一条的文字一字不改**。这是唯一允许的格式调整。

## 可选：如果同时有《量刑建议书》

如果这个案子是认罪认罚、并且手上有检察院的《量刑建议书》，在该份文书末尾追加下面这段（没有就整段省略，不要编）：

```
【量刑建议】
建议刑期：有期徒刑X个月（或：X个月至Y个月）
建议罚金：人民币X元
是否适用缓刑：是 / 否 / 未涉及
量刑情节（照抄建议书上写的）：自首、退赃退赔、认罪认罚……
```

## 输出前请自检（逐条确认，不通过就重来）

- [ ] 「依照《……》……判决如下」这一整句，与原文逐字一致，一个条号都没漏、没多、没改
- [ ] 「本院认为」整段没有被精简或改写
- [ ] 所有金额、刑期、日期、条号与原文完全一致
- [ ] 姓名改成了代号，且同一个人全文一致
- [ ] 没有添加任何原文没有的内容，没有写摘要或点评
- [ ] 发现原文有疑似错误时，**保留了原样**，没有"顺手改对"
- [ ] 每份文书之间用单独一行 `========` 分隔
- [ ] 输出的是纯文本，没有 Markdown 表格、没有加粗、没有额外标题

确认全部通过后，直接输出结果，不要输出自检过程。

## （给我自己看的）为什么这么写

| 条款 | 挡的是什么 |
|---|---|
| 「你是搬运工不是编辑」放最前 | AI 默认会润色。润色一次，`依照《…》第…条` 的原始形态就没了，而那正是被测对象 |
| 「发现错了也照抄，不要提醒」 | **最关键的一条**。AI 看到「引了已废止的司法解释」会好心改成现行的——那等于把答案擦掉了 |
| 「不许编造，没有写无」 | 防止 AI 补一份看似完整、实则虚构的判决书。虚构样本会让假阳性率数据完全失真 |
| 脱敏白名单写成「只动这四类」而不是「注意保护隐私」 | 后者会让 AI 顺手把金额、日期、法条一起"模糊化" |
| 证据必须编号，且「唯一允许的格式调整」 | 我的解析器按 `^\d+[.．、]` 抽证据条目；同时明说这是唯一例外，免得 AI 以为可以自由调整格式 |
| 自检清单放在最后且要求「不要输出自检过程」 | 让模型真的过一遍，又不污染输出 |
