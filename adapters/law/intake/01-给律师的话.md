# 给律师的话（直接复制发出去）

> 微信能发的长度。要点：只要**已公开**的文书、明确**不要**卷内材料、给对方一个用得上的回报。

---

X律师，想请你帮个小忙，占你十分钟。

我在做一个查判决书「依据」的小工具——引的法条现在还有没有效、部门规章有没有被当成裁判依据引、量刑的从宽幅度有没有超出量刑指导意见给的区间、说理段和判决主文里的数字前后对不对得上。

现在它在我自己造的样本上跑得挺好（种进去 12 类毛病抓到 10 类，干净的样本零误报），但**自己出的卷子自己考满分不算数**。我需要几份真文书来验它会不会瞎报。

**想要的**：3–5 份**已公开**的刑事判决书全文——裁判文书网、北大法宝、威科先行上下载的就行，本来就是公开且脱过敏的。最好是带自首、坦白、累犯、退赔、认罪认罚这类量刑情节的普通案件，盗窃、诈骗、危险驾驶都可以。

**不要的**：卷宗材料、未公开的文书、当事人真实信息、任何涉密的东西。只要公开文书，越普通越好。

**唯一的硬要求**：给我的必须是**原文全文**。特别是「依照《中华人民共和国刑法》第……条……之规定，判决如下」这一整句，一个字不能改、不能省、不能润色——那句话正是我要查的对象。文书里如果本来就有错，也请原样保留，那恰恰是最有价值的样本。

**怎么给最省事**：把下面那段提示词连同文书一起丢给你用的 AI（豆包 / DeepSeek / Kimi / ChatGPT 都行），它会一次整理成我要的格式，你把结果整个发我就行，不用自己排版。

**（可选，有就更好）**如果里面有认罪认罚的案子，检察院的《量刑建议书》你手上应该有，一并给我——它能让我多验一层：法院判的和检察院建议的对不对得上。

**回报**：工具跑通之后，你手上任何一份判决书、或者对方的代理词，发我，我给你出一份「引用体检报告」——哪条引了已失效的、哪条根本不能作为裁判依据、量刑幅度有没有越界、前后数字有没有打架，一分钟出结果。写上诉状、再审申请书的时候应该用得上。

## 发出去之后我这边做什么

材料回来先跑收料体检，确认段落认得出来、引用解析得出来，再跑判定：

```bash
node adapters/law/intake.mjs 收到的.txt --split 收到的/   # 一坨多份的先拆开
node adapters/law/intake.mjs 收到的/*.txt                # 这份材料能查到什么程度
node adapters/law/import.mjs 收到的/某某.txt /tmp/x.origin
node compiler/cli.mjs diagnose /tmp/x.origin             # 真正的判定
```

**第一步先看条文库覆盖率，这一步不能跳。** `lawdb.json` 现在只有 20 条样本，
真文书必然引到库外条文。收料体检会把未覆盖的引用逐条列出来，过半时直接把
「A 引用体检」降级为不可做并打 ⚠——**那种情况下 diagnose 报出的「零 error」
不是「引用都合规」，是「一条都没查」，不可采信。**

所以顺序是：先跑一遍 intake 看缺哪些条文 → 把这些条文补进 `lawdb.json`
（`closed_world` 保持 `false`，除非真接了权威法规库）→ 再跑 diagnose 量假阳性。
补库是脏活，但它是一次性的，且第一轮 intake 会直接告诉你要补哪几条。

**这一轮要验的只有一件事：真文书上的假阳性率。**
我的 A 卷是自己造的，跑出 0 个 error 不算数。真文书上如果误报一堆，方案就得改；
如果误报为零而且还抓出了真问题，那才叫站住了。
