# Office fixtures：来源与准入

本目录只保存合成测试夹具或来源明确的公开文件；禁止提交任何客户真实文档。

| 文件 | 来源 / 性质 | 说明 |
|---|---|---|
| `synthetic.docx` | 合成 | 基础 DOCX 解析测试夹具。 |
| `synthetic.pptx` | 合成 | 基础 PPTX 解析测试夹具。 |
| `难例1-嵌套合并跨页.docx` | 合成 | 占位条文与 `R*Cx` 表格数据，覆盖嵌套、合并、跨页表格。 |
| `难例2-文本框脚注图片表单.docx` | 合成 | 占位审核表，覆盖文本框、脚注、图片占位与表单控件。 |
| `船员培训质量管理规则-海事局2019.docx` | 政府公开规章 | 海船员〔2019〕310 号；官方海事系统公开下载页：<https://www.sh.msa.gov.cn/tzgg/75427.jhtml>。同目录 Markdown 为其转换投影。 |
| `make-pptx-fixture.mjs` | 合成夹具生成器 | 生成 `synthetic.pptx` 的零依赖脚本。 |

不得以“已脱敏”为由提交客户文档、客户图纸、客户合同或其派生内容；测试仅可使用合成 fixture 或具有明确公开来源且可再取得的材料。
