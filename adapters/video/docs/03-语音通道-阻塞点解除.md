## 一、四条通道，实测

| 通道 | 结论 |
|---|---|
| 虾盘云 | `list-models --json` 返回 `asr: []`，没有 |

> 我第一轮把阿里那条路判死了（「插件没装」），是判早了。插件能装，而且百炼这条根本不需要 nls-filetrans。

## 二、云端 vs 本地：不是二选一，但差距很大

同一段 120 秒音频：

| 引擎 | 输出 |
|---|---|
| 百炼 fun-asr | 「因为有美金汇率的原因……付款意愿老外高五倍，所以有**三十五倍的市场差价**。国内你能赚 1 万块钱的时候，在海外是 35 万」 |
| 本地 faster-whisper small | 「我感觉那种都不適合 / 就是人类是还是英国年轻的 / 包括跟他原生在这个夺的」 |

whisper small 在中文口播直播上**基本不可用**。速度也差 15 倍（含模型加载 88s vs 5.8s）。

`asr.mjs` 两个引擎都接了：**默认 bl，whisper 只做离线兜底并如实标注降级**（`A-LOCAL-DEGRADED`）。
离线兜底对 U 盘 / 客户机场景仍有意义。

## 五、自己造又自己抓的一个 bug：basis 把两件事塞进了一个字段

给 ASR 加 `basis: transcribed` 之后，校验器报：

```
· [assertion-ratio] 0/19（0%）的价值判断是不可复核的断言
```

**这是错的，而且正是我建这个枚举要防的 A1。** `value: 0.95` 是我的判断；
`transcribed` 只说明 gist 从哪来。两件正交的事塞进一个字段，断言就重新隐身了。

修法：拆开。

```
basis      —— value 的判据来源：measured（有真实反馈数据）/ observed（value 本身可直接观察）/ asserted
gist_from  —— gist 的来源：read-on-screen / transcribed / described
```

改完之后两份 timeline 都诚实地报 **100% 断言**——这才是真相。
`gist_from: transcribed` 且没给可复听 ref 的，直接 error。

## 六、成片暴露的两个错，validate 查不出来

直播那条第一次渲染，60 秒成片里：

1. `[120,150]` 把最强钩子**腰斩**——那句「国内 1 万海外 35 万」从 148.16s 才开始
2. `[543,558]` 选到了铺垫而非卖点——真正的「能一键把这些工具都装上」在 **588.63s，差 45 秒**

两处 ffmpeg 都不报错，`validate.mjs` 也查不出——**时间码完全合法**。又一次 A4。

修法不是加检查，是换方法：**口播型素材根本不该手工估边界。ASR 的句级时间戳就是天然剪辑点。**
`snap.mjs` 做两件事：

```bash
node snap.mjs <timeline> <asr> --find "35万"          # 按台词直接查时间码
node snap.mjs <timeline> <asr> --projection X --write # 把 pick 吸附到句边界
```

吸附后：

```
第1段 [136,154]   → [136.88,157]     首「因为一个是有美金汇率的原因…」
第2段 [662,677]   → [658.6,677.56]   首「然后下面就是还做了一个AI优化大师，是吧？」
第3段 [588,604]   → [588.63,603.18]  首「能一键把这些工具都装上。」
```

第 2 段自动往前吸了 3.4 秒，捡回一个更好的开头。这比二遍抽帧精读**更准也更便宜**。

## 七、诚实边界

- **产品名全错。** ASR 把 Codex→「刻戴斯」、OpenClaw→「龙虾」/「欧莫斯」、u-king.org→「UK点OR」。
  按产品名检索会**整段漏掉 L09**。`bl speech recognize --vocabulary-id` 能修，尚未做。
- **仍然没有情绪通道。** fun-asr 只出文字，不出情绪/语速/音量。腾讯云那条带
  `EmotionRecognition`，但账号未开通。「爆点」很大程度上是语气而非用词。
- **直播的真实判据一条都没有。** 弹幕、点赞、下单、留人曲线全缺（`L-NO-ENGAGEMENT`）。
  100% 的 value 是模型对文本的判断。
- **n=2 仍是 n=2**，且两条素材同一个人、同一个产品。
- **snap.mjs 的 maxDrift=12s 是拍的**，没有在多条素材上调过。
- **依赖联网与百炼账号。** 断网时降级到 whisper，而 whisper 在这类素材上已实测不可用——
  即「有兜底」不等于「兜得住」。
