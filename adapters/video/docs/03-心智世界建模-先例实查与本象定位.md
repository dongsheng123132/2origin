## 二、MWM 是什么（只摘可复核的形式化部分）

联合状态分解：

$$s_t = (s_t^{phy},\; s_t^{ment})$$

物理侧（Eq. 6）：$s_t^{phy} = (O_t, C_t, R_t^{phy}, E_t)$ —— 物件 / 角色 / 空间与接触关系 / 环境。

心智侧（Eq. 7–8）：每个行动者 $i$ 的心智状态是九元组

$$m_t^i = (\mathrm{id}, b, q, g, \iota, e, d, n, c)$$

identity / **beliefs** / attention / goals / intentions / emotions / dispositions / norms / behavioral constraints。

目标投影（Eq. 13）：

$$o_t^\epsilon = \Omega_\epsilon(s_t) = \big(\Omega^{phy}_\epsilon(s_t^{phy};\kappa_t^\epsilon),\; \Omega^{ment}_\epsilon(s_t^{phy}, s_t^{ment};\rho_t^\epsilon)\big)$$

$\kappa$ / $\rho$ 是两个过滤参数——**这就是「投影按接收者裁剪」的形式化**。

MENTIS 六阶段（训练无关，纯 LLM 编排）：

| # | 阶段 | 产出 |
|---|---|---|
| 1 | State Parsing | 结构化 $s_t$，拆两侧 |
| 2 | Observation Rendering | target 的局部视图 $o_t$ |
| 3 | Action Decomposition | 候选动作拆成物理分量 + 心智分量 |
| 4 | Branch Simulation | 每个选项如何**同时**更新两侧 |
| 5 | Branch Evaluation | 三个加权分：mental consistency .45 / physical plausibility .35 / social appropriateness .20 + safety veto |
| 6 | Deterministic Decision | 确定性选最高分 |

瓶颈（§7.2）：`Transition simulation is the largest single bottleneck`；`Oracle gains are sub-additive`。

### 主结果（Table 4，PDF 实读，448 条全集，final-action F1 %）

八个模型：OpenAI `gpt-5.6-sol` / `5.5` / `5.4` / `5.4-mini` / `4.1`，
Anthropic `fable-5` / `opus-4-8` / `haiku-4-5`。**人类参照 98.5。**

| 梯级 | 系统 | Avg | 相对上一级 |
|---|---|---|---|
| S0 | choice-only floor（只给选项） | 31.3 | — |
| S1 | direct answer | 63.3 | +32.0 |
| S2 | + CoT | 74.6 | **+11.3** |
| S3 | + SC@6 | 77.9 | +3.3 |
| S4 | + free-text state | 80.3 | +2.4 |
| S5 | + structured state | 82.6 | +2.3 |
| **S6** | **full MWM (MENTIS)** | **87.9** | **+5.3** |
| A1 | − mental（消融） | 75.8 | −12.1 |
| A2 | − physical（消融） | 71.4 | −16.5 |
| A3 | decoupled transition（消融） | 81.5 | −6.4 |

两条**论文自己没有强调、但读表就能看出**的事实，本页认为必须记下来：

1. **CoT 一档就吃掉 +11.3，是整条梯子最大的单级增益。** 全 MWM 相对朴素 CoT 是 +13.3——
   两者同量级。「显式建心智」的增量真实存在（S5→S6 还有 +5.3），但**它不是从零到一，是从 74.6 到 87.9**。
2. **拆掉物理通道（−16.5）比拆掉心智通道（−12.1）更疼。** 站点那句
   "the decisive factor is whether the mind is modeled" 站得住（S6 每格都赢），
   但**按消融代价排序，物理仍是更大的单一通道**。站点没写这一层。

论文自己点出的规律（Table 16）：`S6-S1` 增益对**越弱的模型越大**（`gpt-4.1` +28.0 vs `5.6-sol` +21.1），
消融代价同理（`S6-A2` 从 12.7 涨到 19.5）——**结构补偿规模**。这条对本象是好消息：
协议式外骨骼在弱模型上收益更大。

## 二·五、哲学对照：两边在说同一件事，方向相反

论文 §3.2 有三段澄清，逐句都能在本象里找到对位。**这是全页最值得读的一节。**

| MWM 原文（p7–8） | 本象里的同一句话 |
|---|---|
| "the target observation $o_t^\epsilon$ is therefore **a first-person rendering of the global state, not a copy of it**" | 「投影是按需生成的视图，**永不真源**」 |
| "**The world model is not the agent.** … the target agent acts from an egocentric observation, while the world model simulates consequences from a richer third-person state" | 「本象持有全量，影子面向具体接收者」 |
| "The target **may be wrong, uninformed, biased, or socially constrained**; the world model still represents the hidden variables that explain why the target's observation differs from the global state" | 「投影必须注明丢弃了什么」（`must_disclose_truncation`） |
| "**MWM is an objective simulator, not simulated consciousness.**" | 「本象不是万能 DOM」——反面清单式的自我设限 |

论文的核心主张框（p8）：

> *"The minimal object of simulation for social decision-making is not a physical trajectory alone
> and not a theory-of-mind answer alone. It is an action-conditioned transition over a coupled state:
> **physical variables constrain what can happen, while mental variables determine what the same
> happening means to the agents involved.**"*

和那个例子：

> *"A cup handed across a table is one physical event, yet it may be an apology, a request, an act of
> compliance, or a gesture of care, and **only the world model holds the mental-social state that
> disambiguates it**."*

**一源万影的社会学版本。** 同一个物理事件，多重语义投影；能消歧的东西只在本源里。
本象讲这句话时举的例子是 PPT 的结构影子 / 语义影子 / 视觉影子，MWM 举的是递杯子。
同构。

### 分歧点（也是本页第 9 条主张的来源）

两边对「影子」的态度是**反的**：

| | 本象 | MWM |
|---|---|---|
| 影子的地位 | **认识论上次等**——有损、可重建、不得当本体用 | **因果上首要**——行动者只能从 $o_t$ 行动（Eq. 3） |
| 关心的失效 | 投影**少给**了什么（丢弃未声明） | 投影**多给**了什么（泄漏） |
| 由此推出的约束 | `must_disclose_truncation` | $\Omega_\epsilon$ 的 $\kappa$ / $\rho$ 过滤 |

合起来是一句本象目前没写下来的话：

> **影子在认识论上次等，在因果上首要。**

后半句是 MWM 的（Eq. 3：`TARGETAGENT: `$o_t^\epsilon \mapsto a_t^\epsilon$，行动只以观察为条件），
并置是本页的。它对本象的后果很具体：**上下文编译器一直在做 mental world modeling**——
三层上下文（atlas / graph / exact）就是给 AI 造的心智世界，而协议现在对它的全部要求只有
「可重建、注明丢弃」，**没有「能预测这个 agent 拿到它之后会干什么」**。

## 三、方言自检表：4 格半填得出

| 概念 | MWM 的「它」 | 判定 |
|---|---|---|
| **对象** | target（被建模的行动者）+ 场景物件 | ✅ 就是对象 |
| **引用** | 心智状态怎么被引用 | ❌ **这格是坏的**，见下 |
| **投影** | $\Omega_\epsilon(s_t)$，按接收者裁剪的局部视图 | ✅✅ 比视频方言还标准 |
| **事务** | 动作 = 引用什么 + 断言什么 + 改什么（且同时改两侧） | ✅ 就是语义事务 |
| **校验** | 每阶段 emit 可检查中间件；448 标注跑 final-action F1 | ✅ 同一个本能 |

**不是新协议。** 与 `00-反思` 对视频下的判断同构：不用发明新东西。

### 唯一顶不住的：可信引用 5 属性

| # | 属性 | 心智状态 |
|---|---|---|
| 1 | 极小 | ✅ |
| 2 | 稳定 | ❓ 信念会变，且无指纹能证明变没变 |
| 3 | 可解析 | ❌ 视频有 `ffmpeg -ss` 当解析器；**心智状态的解析器不存在**，回不去复核「他当时到底信不信」 |
| 4 | 新鲜 | ❌ 无指纹，源变了不会主动失效 |
| 5 | 单一真源 | ❌ 真源在行动者脑子里，手上永远只有副本 |

→ **心智状态在本象里天生立不成「对象」，只能立成 `basis: asserted`**，必须带 `criterion` + `as_of`。
解法 [dialect-video](../spec.md) 的 basis 三档已经写好了；心智状态是这条规则最极端的用例——
它**永远**升不了格。

**一个有意思的分叉：** 在 Mentis 那种全知模拟器里，心智状态是模拟器**自己写的**，
有真源、可解析、可复核 → 这时它是合格的本象对象。对真实世界的人则没有。
Menti-Bench 的 448 条全属于第一种，所以它的 benchmark 成立；方法推到真实 agent 上时前提就没了。

## 四、硬证据：Story 方言已经在存心智状态

`../../../docs/03-协议草案-v0.1.md:229-232`：

```json
"assertions": [
  "bai-yao-betrayal-remains-secret",
  "zhao-qi-remains-alive"
]
```

第二条是物理事实。**第一条是纯心智断言**——「remains secret」展开是「不存在对象 X 使得 X 相信白瑶背叛」，
它约束的不是世界怎么样，是世界里的人**相信**世界怎么样。对应 MWM 九元组里的 $b$（beliefs），
九分之一。

| | 现状 | 缺什么 |
|---|---|---|
| 结构 | 一个字符串塞进 `assertions[]` | 无 `{holder, proposition, polarity}` |
| basis | 无 | 天然是 `asserted`，却和物理事实混在同一个数组 |
| 时效 | 无 `as_of` | 秘密有水位，秘密会泄 |
| **对谁** | **无** | 秘密对赵七是秘密，对白瑶自己不是 |

最后一行最要命：这是个**全局命题**，而秘密从来不是全局的。
按 09-引用优先四问量它：真源是谁？——没有，从正文推出来的，推的过程没留下，回不去复核。
**双份账本的心智版。**

## 五、本象真正剩下的位置（可复核）

GitHub API 实拉 `mentis/schema.py`：

```python
class WorldState(LooseModel):
    physical_state: PhysicalState
    mental_state: MentalState

class Observation(LooseModel):
    physical_observation: PhysicalState
    mental_observation: MentalState
```

两个**互相独立**的 `LooseModel`，字段全是 `Optional[dict[str, Any]]`，`extra="ignore"`。

**Mentis 确实防泄漏——但防的方式是叮嘱，不是校验。** 实拉 `mentis/prompts.py`：

| 行 | 原文 | 性质 |
|---|---|---|
| 76–80 | `physical_observation must ... include only [accessible] ... use null for inaccessible scalar fields` | 提示词指令 |
| 83–84 | **`Do not copy hidden global mental state`** | 提示词指令 |
| 44 | `[characters] away or out of earshot at a moment do not know what happened then`（视频模态） | 提示词指令 |
| 60 | `Use only the story input; do not use any question or answer options when constructing s_t` | 提示词指令 |
| 123–124 | `Do not use the question, the scene, option correctness, or cross-option comparison` | 提示词指令 |

而执行层 `engine.py:141-149`：

```python
async def _render_observation(...) -> Observation:
    reply = await ...(prompt=prompts.observation_prompt(state.as_dict(), target_agent),
                      schema=Observation, ...)
    return Observation.model_validate(reply.data)
```

`model_validate` 校验的是**形状**，不是**包含关系**。全管线没有一个谓词检查
$o_t$ 里的事实是否都在 $s_t$ 里、且对 target 可见。

### ⚠️ 重大修正：他们有泄漏检查，而且是本页读完附录 F 才发现的

本页早期版本写「整条管线的认识论保证全部依赖模型听话」「可检查性建立在一串不可检查的承诺之上」——
**两句都过头了，已删。** 附录 F.1 与 §J 的实情：

**MWM 定义了 Perspective-leakage rate，是一个正式评测指标：**

> *"**Unknown** inside a target observation asserts that the target cannot know the fact at the
> decision moment; a prediction that supplies the value **commits perspective leakage and is
> penalized**. Judge prompts encode both conventions explicitly."*
>
> *"**Perspective-leakage rate.** A target observation leaks if it asserts a fact the target cannot
> access at the decision moment (a field the gold observation marks Unknown, or a global-state fact
> outside the target's perceptual and epistemic reach)."*

而且判分本身也有外部锚：
*"Before any judged number enters a headline claim, LLM-judge scores are correlated against human
ratings on a stratified subsample and reported with that agreement."* ——**A2 他们处理了。**

三层全都有东西，本页原来只看到第三层：

| 层 | MWM / Mentis | 判定 |
|---|---|---|
| **基准层**（这批数据整体会不会被猜中） | S0 choice-only floor = 31.3 + 通道干预（§6.2 / Table 8） | ✅ 有，且硬 |
| **评测层**（某次预测的 $o_t$ 泄没泄漏） | Perspective-leakage rate，金标准 `Unknown` + LLM judge + 人类相关性 | ✅ **有** |
| **运行时**（这一次生成的 $o_t$ 当场拦不拦） | 提示词指令 + `model_validate`(shape) | ❌ 无谓词 |

### 修正之后，本象真正剩下的位置（收窄了很多，但更硬）

只剩一条，而且它是个**表示问题**，不是缺功能：

> **金标准用两个不同的标记承载判定，而运行时 schema 把它们塌成同一个 `null`。**

| 标记 | 金标准里的含义 | 判定后果 |
|---|---|---|
| `unspecified`（全局态字段） | 标注**有意留空** | 填或不填**都不罚** |
| `Unknown`（目标观察字段） | 目标在决策时刻**不可能知道** | **填了就是泄漏，要罚** |

论文原话：这两条 "are **load-bearing** for evaluation"。

而 `prompts.py` 让模型对两种情况写同一个值：
L79–80 `use null for inaccessible scalar fields`、L85–86 `use null for unavailable fields`。
`schema.py` 里也只有 `Optional[...] = None`。

**于是 `null` 同时意味着「不适用」「目标不可知」「模型没填」三件事。**
包自己说不清哪个是哪个 → **泄漏判定只能拿外部金标准做，无法在包内完成。**

这正是 09-引用优先 与 08-第七要素 合起来那件事：
**承载判定的区分必须进包，否则判定就得靠包外的东西，而包外的东西不总在场。**

| | MWM | 本象的增量 |
|---|---|---|
| 泄漏概念与指标 | ✅ 提出、形式化、有金标准、有人类锚 | 引用，**不得声称原创** |
| 运行时可自证 | ❌ `null` 三义，包内判不了 | **这是位置** |
| 无金标准场景 | ❌ 指标依赖 gold `Unknown` | **这是位置** |

⚠️ 但要老实说：本象目前**也没有**解法。把 `null` 拆成
`{not_applicable, unknown_to_target, not_filled}` 三个哨兵是显然的第一步，
但「目标可访问性」本身怎么被确定性地表示（论文里是 $\kappa_t^\epsilon$ / $\rho_t^\epsilon$ 两个抽象参数）
**没有现成答案**。本页只指出缺口在哪，不声称能补。

| | MWM / Mentis | 本象 |
|---|---|---|
| 心智状态该进世界状态 | ✅ 提出并形式化 | 引用，不得声称原创 |

| **心智断言的 basis / as_of / holder** | ❌ 自由字典 | **这是位置** |

## 六、值得抄的一条：A3

Mentis 第 5 阶段只出判断分，第 6 阶段是确定性加权选择。**判断权与决策权分开了。**

`00-反思` §三·A3 原话：「判断权和决策权全部集中在一个不可复核的模型手里……这不是 A3，这是 A2 的加重情形。」
**Mentis 切了这一刀，视频 v0 没切。** 这是现成可抄的结构，与心智状态无关，视频方言的 `value` 打分直接适用。
