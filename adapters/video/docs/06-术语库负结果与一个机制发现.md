# 06 · 术语库护城河：negative；但撞见了一个更强的机制

**Status:** 实验记录 · 含负结果与设计缺陷自述
**Date:** 2026-08-09
**起因：** 判断「字幕工具的护城河是累积的术语库（本境）」，需要验证它跨素材有没有复利

---

## 一、术语库迁移测试：负结果

从素材 A（27 分钟直播）学到 8 条已确认的「误听→正确」映射，在三条新素材上测命中：

```
素材                      ASR字数   库中误听命中
A 直播 27min（来源）        4596     5/8
B 直播 4min（同人）         1214     0/8
C 录屏 10min（同人）        2685     0/8
D 产品演示 69s（跨领域）      355     0/8
```

**0 迁移。**

### 我的测试设计有缺陷

B 是一段人物采访，
通篇没有任何产品名——它根本不构成迁移测试。这一条数据无效。

C 有效：同领域（讲 Kimi、DeepSeek、一个叫「一搜」的工具），但**讲的是不同产品**。

### 但结论仍然成立，而且原因更根本

同一个 Codex，在不同语境里被听成「刻戴斯」「科德斯」「克拉克的」。
**误听形式随语境变，记住某一种没用。** 「错→对」这个数据结构本身选错了。

---

## 二、真正的机制：它是在读屏幕，不是在听

追查「omni 为什么能听对 Codex/Hermes 而三个专用 ASR 全错」时发现的。

**对照实验**：同一段音频（直播 588–604s，他在念工具箱里的工具名），
一版带原画面，一版换成纯黑屏，其余全部相同（同模型、同提示词、temperature=0）。

| | Codex | Hermes |
|---|---|---|
| **有画面** | `codex` ✅ | `Hermes` ✅ |
| **黑屏（只有声音）** | `codebase` ❌ | `homeos` ❌ |

**同样的声音，有屏幕就对，没屏幕就错。**

那一刻屏幕上正是 ClawX 工具箱界面，明晃晃列着
`Claude Code CLI / Codex CLI / OpenClaw 桌面版 / Hermes Agent`。

### 这解释了三件之前想不通的事

1. **为什么三个专用 ASR 全错**：那个信息**根本不在音频里**。
   不是模型不够好，是通道里没有。纯 ASR 类产品（剪映、通义听悟、腾讯会议）
   在这类内容上的专有名词错误**不可修复**。
2. **为什么教程素材里 Codex/Hermes 一次都没出现在转写里**：他指着屏幕说
   「这个是最好的编程终端」，名字**在画面上，不在嘴里**。
3. **为什么术语库迁移失败**：正确机制从来不是"记住误听"，是"看画面"。

---

## 三、但这个发现是 n=1

四次对照里，只有一次出现差异。另外三段（`src.mp4@30s`、`C@60s`、
直播 765s / 795s）有画面与黑屏产出几乎相同。

**那三次不是反例**——那些片段里他没有点名任何产品，画面上也没有正在被指涉的专有名词，
所以没什么可读的。但它们说明了一件商业上重要的事：

> **「画面上有名字且正在被指涉」的句子，在素材里占比很低。**
> 这个优势只作用在一小部分字幕上——**但那恰好是最要命的那部分**
> （产品名、价格、代码、客户名）。

要把它变成可宣称的能力，需要一个**专门挑这类片段**的测试集，
n=1 不足以定量。

---

## 四、商业含义：定位要改

| 原定位 | 修正后 |
|---|---|
| 「更准的字幕工具」 | 「**看得见屏幕的字幕**」 |
| 护城河 = 累积术语库 | 护城河 = **多模态通道**（竞品结构上没有） |
| 竞争对手会追上 | 纯 ASR 架构**追不上**——信息不在音频里 |

**锁定的场景**：屏幕上有字的内容 —— 软件教程、技术直播、编程课、产品演示、
**在线会议（共享屏幕 / PPT）**、发布会。

会议场景尤其成立：**PPT 上的项目代号、客户名、术语全在屏幕上**，
而飞书妙记 / 腾讯会议 / 通义听悟只听音频。这解释了为什么它们的纪要里
专有名词总是错——不是它们不努力，是它们没看。

**术语库不废弃，但降级**：从"护城河"降为"兜底"——
处理那些既没念清楚、屏幕上也没有的词。

## 五、诚实边界

- **屏幕读取效应 n=1 片段。** 一次决定性对照（两个词同时翻转），三次无差异对照。
  未量化，不能宣称"准确率提升 X%"。
- **术语库负结果 n=3 素材，其中一条（B）测试设计无效。** 有效样本只有 C 和 D。
- **没有跟真正的竞品对比过。** 全程没有实际跑一次剪映/通义听悟做对照，
  「它们在这类内容上必错」是从机制推的，不是测出来的。**这是最该补的一条。**
- **成本未测。** `bl` 没有用量命令，一小时素材要花多少钱还不知道，
  定价能不能成立无法判断。
- **omni 也会错。** 同一段里 `Claude Code` 被写成 `CloudCode`，
  屏幕上明明写着 `Claude Code CLI`。看见 ≠ 抄对。
