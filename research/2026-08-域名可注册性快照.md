## 三、复查方法

```bash
# 注册局 RDAP 直查：404 = 未注册，200 = 已注册（比 whois 稳，无速率封锁）
curl -s -o /dev/null -w "%{http_code}\n" https://rdap.publicinterestregistry.org/rdap/domain/benxiang.org   # .org
curl -s -o /dev/null -w "%{http_code}\n" https://www.registry.google/rdap/domain/benxiang.dev              # .dev/.app
curl -s -o /dev/null -w "%{http_code}\n" https://rdap.identitydigital.services/rdap/domain/benxiang.io     # .io
curl -sL -o /dev/null -w "%{http_code}\n" https://rdap.org/domain/<域名>                                    # 通用兜底

# 对照组（必须返回 200，否则是网络问题不是"域名可注册"）
curl -s -o /dev/null -w "%{http_code}\n" https://rdap.publicinterestregistry.org/rdap/domain/google.org
```

⚠️ **NS 查询（`nslookup -type=NS`）只能当粗筛**：已注册但未配置 NS 的域名会假报"可注册"。
本次结果已用 RDAP 逐个复核，未采信 NS 单独证据。
