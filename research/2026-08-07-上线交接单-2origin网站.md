### 步骤 2：在 Vercel dashboard 连接 GitHub 仓库（推荐方式）
不依赖 CLI 登录，用户直接网页操作：
1. vercel.com → Add New Project → Import GitHub repo `dongsheng123132/2origin`
2. vercel.json 已配置 rootDirectory=website，Vercel 自动识别纯静态站
3. Framework Preset 选 "Other" 即可（无构建）
4. Deploy → 得到 `<project>.vercel.app` 预览 URL
5. 绑定 2origin.org：项目 Settings → Domains → 添加 2origin.org
6. Cloudflare DNS 加 CNAME：`2origin.org → <project>.vercel.app`

> 备选：若要用 CLI（需交互终端，Claude 无法代跑）：
> ```
> ! vercel login
> cd website && vercel link --yes && vercel --prod
> ```
