# Cases：公开来源与资产边界

`us-sandiego-ds3179-evidence.origin/` 与 `us-sandiego-ds3179-template.origin/` 使用 City of San Diego 公开的 DS-3179 Construction Plan DXF 模板；来源：<https://www.sandiego.gov/development-services/forms-publications/design-guidelines-templates>。保留的 DXF 与其派生包均带来源和哈希，可公开复核。

CAD 窗洞审计案例只可基于合成 fixture 或上述公开数据。原 `cad-window-audit.origin` 的 provenance 表明其来自 `customer-controlled-original`，即使原件未入仓，公开包仍含其派生坐标、对象与摘要；它不符合本仓库客户资产边界，已移出，不再保留。
